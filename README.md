E-Commerce Sales Dashboard – Excel Project

Project Overview

Developed an interactive E-Commerce Sales Dashboard using Microsoft Excel to analyze sales, quantity, profit, customer performance, and payment methods. The dashboard provides meaningful business insights through interactive charts and filters.

Key Performance Indicators (KPIs)

- Total Sales Amount: 438K
- Total Quantity Sold: 6K
- Total Profit: 37K
- Average Order Value (AOV): 121K

Key Business Insights

1. State-wise Sales Analysis

- Maharashtra recorded the highest sales of 102K.
- Madhya Pradesh ranked second with 87K.
- Uttar Pradesh contributed 38K in sales.
- Delhi and Rajasthan contributed 23K and 22K respectively.

2. Category-wise Quantity Analysis

- Clothing contributed 63% of total quantity.
- Electronics contributed 21%.
- Furniture contributed 17%.

3. Payment Mode Analysis

- Cash on Delivery (COD): 44%
- UPI: 21%
- Debit Card: 13%
- Credit Card: 12%
- EMI: 10%

4. Monthly Profit Analysis

- November recorded the highest monthly profit.
- January, February, and March also showed positive profit performance.
- May, July, September, and December recorded negative profit.

5. Sub-Category Profit Analysis

- Printers generated the highest profit.
- Bookcases ranked second.
- Sarees, Accessories, and Tables also contributed to overall profit.

6. Customer-wise Sales Analysis

- Harivansh recorded the highest sales among the displayed customers.
- Madhav ranked second.
- Madan Mohan, Shiva, and Vishakha also contributed to sales.

Tools and Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

Dashboard Features

- Interactive quarterly filters
- City-wise filtering
- KPI cards
- Monthly profit visualization
- State-wise sales comparison
- Category and payment mode analysis
- Customer-wise sales analysis

Project Objective

The main objective of this project is to transform raw e-commerce data into meaningful insights, identify sales trends, evaluate profitability, and support data-driven business decisions.
